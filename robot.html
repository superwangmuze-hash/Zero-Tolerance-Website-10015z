How we work

FROM IDEA
TO ROBOT

Building a robot takes planning, creativity, and iteration. We learn by working through each stage together.

01 / DESIGN

Plan the approach

We start by understanding the challenge, then compare ideas and plan a design that can meet its demands.

02 / BUILD

Make it work

Careful construction turns a design into a robot. We make adjustments as we learn more about how each part works together.

03 / PROGRAM

Put it in motion

Code gives the robot instructions. Testing helps us refine those instructions and improve how the robot responds.
